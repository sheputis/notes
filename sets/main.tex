\section{Definitions}

\subsection{Axiom}

An axiom is a premise assumed to be true, that itself requires no internal proof.
It is then used to build theorems, that are proved using logical statements based
on axioms. The difference between a theorem and an axiom is that they are both
statements about a mathematica system, but theorems are logical consequences
of the axioms, proven or disproven, while axioms need no proof as per definition.

\subsection{Definition}

A definition is a statement that does not add a restriction on a theory, it
introduces a concept and assigns a label to it. It is just a description, it needs
no proof. If it would need proof, it would be a theorem.

\section{Set Theory}

\subsection{Mapping/Function}

A Mapping or a Function (synonyms) is generally denoted as $f: X \to Y$. It takes an
input point from the domain $X$ and maps it onto its codomain $Y$. The set of points
that it maps onto inside of $Y$ is called an image of $f$.

Before defining what a mapping is, we need to define a few other things first:

\subsubsection{Ordered Pair}

\begin{equation}
  (a, b) \coloneqq \{\{a\}, \{a, b\}\}
\end{equation}

This works because $(a, b) = (a, b)$ and $(a, b) \not = (b, a)$.

\subsubsection{Cartesian Product}

A cartesian product is defined as

\begin{equation}
  X \cross Y \coloneq \{ (x,y): x \in X \land y \in Y \}
\end{equation}

\subsubsection{Map is a set}

A map/function is defined as a subset of a cartesian product between two
sets with two additional criterias.

\begin{equation}
  f \text{is a set} f \subseteq X \times Y \text{satisfying properties} T \text{and} Q
\end{equation},
where the criterias are
\begin{itemize}
  \item `Totality`
        \begin{equation}
          T: \forall x \in X \exists y \in Y, (x, y) \in f
        \end{equation}
        This means that the entire domain $X$ is mapped to $Y$, there is not a single point
        in $X$ that does not get mapped onto the codomain $Y$.
  \item `Uniqueness`
        \begin{equation}
          U: \forall x \in X \forall y_1, y_2 \in Y, ((x, y_1) \in f \land (x, y_2) \in f) \implies y_1 = y_2
        \end{equation}
        or, equivalently
        \begin{equation}
          U: \forall (a,b), (c,d) \in f, (b \not = d) \implies (a \not = b)
        \end{equation}

        This means that for all points in $X$ there exists only a single point in $Y$ that
        it maps to. It can not map to two different points at the same time.
\end{itemize}
for such an $f$, there is an $x \in X$ and its unique mapping in $y \in Y$ is denoted by $f(x) = y$

\subsection{Injective Functions}

A function $f: X \to Y$ is injective if

\[
  \forall a, b \in X: a \neq b \implies f(a) \neq f(b)
\]

or the contraposition

\[
  \forall a, b \in X: f(a) = f(b) \implies a = b
\]

\subsection{Surjective Functions}

A function $f: X\to Y$ is surjective if

\[
  \forall b \in Y,\; \exists a \in X : f(a) = b
\]

\subsection{Bijective Functions}

A function $f: X \to Y$ is bijective if it is both injective and surjective.
In this case, there exists an inverse function $f^{-1} : Y \to X$.

\subsection{Cardinality}

Cardinality is a generalized notion of size for sets. It is defined as an equivalence
relation between sets. All sets between which a bijection exists form an equivalence
class. Each such equivalence class is called a Cardinality.

\begin{equation}
  \abs{X} = \abs{Y} \iff \exists \text{bijection} f: X \to Y
\end{equation}

\subsection{$\abs{X} \leq \abs{Y}$}

Now we need to define the notion of what it means for one set to be smaller
or equal than another. The symbol $\leq$ does not yet carry meaning in the
context of cardinalities; we must define it.

\begin{equation}
  \abs{X} \leq \abs{Y} \iff \exists \text{injection} f: X \to Y
\end{equation}

\subsection{$\abs{X} \geq \abs{Y}$}

Again, just because we defined $\leq$ does not mean we automatically
get $\geq$. We also need to define it. We use a symmetry argument

\begin{equation}
  \abs{X} \geq \abs{Y} \iff \abs{Y} \leq \abs{X}
\end{equation}

Which, by unwinding the definitions, means that there must be an injective
mapping $f: Y \to X$.

\subsection{Notes on Cardinality/Ordinality}
Cardinality answers the question of whether two sets $X$ and $Y$ are of the same size.
It is a generalized notion of size for a set. It is defined two more fundamental
definitions: an injective mapping means one set is bigger or equal than the other:
meaning one has bigger or equal Cardinality than the other.
and a surjective mapping means one set is smaller or equal than the other meaning one
has smaller or equal cardinality than the other. Now
if both are the case at the same time, then the two sets inevitably have an equal Cardinality.
There is litterally nothing else to this definition, it specifically defines a notion
of size based on comparisons with surjective and injective (and what follows 'bijective')
maps -> which means that the notion of size is purely comparative, there is no absolute
size implied by this definition alone.

Now later on one might then ask, ok but buddy boy, in the case of finite sets, i want to
know the exact size of a set, and i want a number for it. How does the Cardinality help
me? Well Cardinality alone does not help you at all, we need another definition to help
us count the set elements, and hence the absolute size of a set. That is done by Defining
'ordinal numbers'. We can construct such numbers as sets, and if we have the notion of
a size for such ordinal numbers (will get to that later), and then if we have a bijective
mapping to some othe set $X$, then we know that some other set $X$ has the same Cardinality
as this ordinal number, and the ordinal number has a known size which is an integer for finite
sets, and hence we can claim that $X$ also has that same integer size. <-- this is basically
how this the special case of counting finite sets derives from the combination of Cardinality
and Ordinal numbers.

Now the question is, how are the Ordinal Numbers defined. John Von Neumann defined ordinals
with a recursive relation $ \alpha = \{ \beta \mid \beta < \alpha  \}$, and a starting
element $\alpha_0 = \Phi$, the empty set. Then we simply define the empty set as representing
a natural number $0$ and we have the concept of counting by simply following the recursive
relation where $1$ is $\alpha_1 = {\phi}$ and $2$ is $\alpha_2 = { \alpha_0, \alpha_1 } = {\Phi, {\Phi}}$
and so on. And we now see that there is an order through the recursive relation that allows the 'counting',
and by counting we mean adding 'one new element' to a set, so the previous set is smaller by the next by
1 element. End the empty set is defined then explicitly to be of size 0 because it has no elements, then
naturally due to the recursive relation the next one will be 0+1, hence 1, and then the next one 1 + 1 = 2
and so on. Now all we need to do is to find bijective mappings between ordinal numbers and other finite
sets and voila, since they have the same cardinality, we know they have the same size, and since we know
the size of a finite ordinal explicitly, well then we now also now explicitly the size of the other set
which can be mapped to with a bijection from the ordinal number.

However if we let the ordinal go to infinity, we no longer have an absoute size because infinity does not
have a 'last element'.

\subsection{Power Set}

An important kind of set is a power set. If we have a set $X$, then its power
set $\mathcal{P}(X)$ is a set containing all subsets of $X$, including the empty set and the
entire set $X$.

\[
  \mathcal{P}(X) = \{\, Y \mid Y \subseteq X \, \}
\]

\[
  f: X \to \mathcal{P}(X)

The idea is to show that there exists a set that breaks the initial premise that we assumed to
be true: that there exists such a bijection $f$.

Before doing so we take notice of the fact that the mapping $f$ can happen in two ways:

\begin{equation}
    x \in f(x)
    \label{eq:uninteresting_property}
\end{equation}

\begin{equation}
    x \notin f(x)
    \label{eq:interesting_property}
\end{equation}

\subsubsection{Detour To No Contradiction}

Actually the second property ~\eqref{eq:interesting_property} is the interesting one, but for the sake of exploring,
let us look at the first property ~\eqref{eq:uninteresting_property} and construct a set of all elements that satisfy that property

\[
\mathcal{B} = \{\, x \in X \mid x \in f(x) \,\}
\]

So now we want to find an $x_i$ such that $f(x_i) = \mathcal{B}$. There are two possibilities, either
$x_i \in \mathcal{B}$ or $x_i \notin \mathcal{B}$.

\begin{itemize}
  \item If $x_i \in \mathcal{B}$, then there is no contradiction because the constraint in the definition
        of $\mathcal{B}$ allows it.
  \item If $x_i \notin \mathcal{B}$, then there is also no contradiction because since $x_i$ is now not
        pointing to a set where it itself is an element, then due to the definition of $\mathcal{B}$, it
        is automatically also not part of it.
\end{itemize}


\subsubsection{The Property Leading To Contradiction}

Now back to the interesting property ~\eqref{eq:interesting_property}: let's construct a set that satisfies it.
A set of all $x$ that do not map to an element of $\mathcal{P}(X)$ that contains itself.

\[
\mathcal{D} = \{\, x \in X \mid x \notin f(x) \,\}
\]


The question is, can we find an $x_i$ such that $f(x_i) = \mathcal{D}$
There are two possibilities for it, either $x_i \in \mathcal{D}$ or $x_i \notin \mathcal{D}$.

\begin{itemize}
  \item If $x_i \in \mathcal{D}$, then, by definition, $x_i$ indexes a set that it itself is a part of.
        That is a contratiction, because $\mathcal{D}$ is defined as a set of elements that point to a
        set that does not contain itself.
  \item The other option is that $x_i \notin \mathcal{D}$. If that is the case, then by definition of
        $\mathcal{D}$, $x_i$ must be a member of $\mathcal{D}$, which is a contradiction.
\end{itemize}
